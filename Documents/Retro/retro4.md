## Retro for sprint 4

We did Start Stop Continue for our retro.

# Start
- Start paying attention to AI slop imports, meaning sometimes AI makes completely unnecessary changes that just moves for example dependencies in to a different order
- Start making branches public from the get go, push the branch visible to others when you start working on it.

# Stop
- Stop ignoring conflict resolutions. Some pull requests resulted in old code coming back and changes being discarded
- Stop ignoring pull request reviews quality. Some of the mistakes made could have been prevented with better reviews on the pull requests.
- Stop doing things at the last minute. Some changes were made just before meeting with our client. 

# Continue
- Continue having active communication within the team, even during PR mess
- Continue solving problems without panic
- Continue keeping the team updated on what you are doing
- Continue using the new review system of PR draft -> co-pilot review -> person review -> merge
- Continue with good team work

# What we want to improve on this sprint
- We want to be extra careful with our conflict resolves, so that no older updates are merged back to production
- We want to look into pull request reviews more deeply, so that mistakes are noticed earlier
- We want to avoid last-minute changes by finishing work earlier and creating PRs sooner
