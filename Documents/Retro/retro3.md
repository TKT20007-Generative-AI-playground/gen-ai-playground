## Retro for sprint 3

We did Start Stop Continue for our retro.

# Start
- Start using a new pull request workflow: first open a draft PR, request Copilot review, make changes based on the feedback, and ensure CI passes before requesting human review
- Start doing PR reviews as soon as possible so work does not get blocked
- Start self-reviewing your own code before asking others to review it
- Start running local tests before committing and opening a pull request

# Stop
- Stop making last-day changes right before the sprint ends
- Stop ignoring other people’s work and make sure we stay aware of what others are doing

# Continue
- Continue having active communication within the team
- Continue talking openly about work, blockers, and ideas
- Continue with the practice that one approval is enough for merging
- Continue having a scrum master each sprint
- Continue reviewing others’ pull requests often

# What we want to improve on this sprint
- We want to consistently follow our new pull request practice: open a draft PR early, request Copilot, iterate until CI passes, and then open the real PR and request human review
- We want to avoid last-minute changes by finishing work earlier and creating PRs sooner
- We want to keep improving communication around ongoing work so that reviews and collaborations happen smoothly and no one’s work is ignored
