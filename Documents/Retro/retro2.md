We did Start Stop Continue for our retro.

# Start
- Start a system that decides who reviews pull requests
- Start being more active in reviewing pull requests
- Start prioritizing pull requests

# Stop
- Stop procrastinating
- Stop leaving tasks until the last minute

# Continue
- Continue reporting progress
- Continue to use the role of scrum master
- Continue to ask for help
- Continue to be on time

# What we want to improve on this sprint
- We want to aim to complete our tasks in advance so that stress does not build up at the end of the sprint due to time pressure
- We want to use our agreed system to ensure that pull requests are reviewed more efficiently
- Going forward, we will prioritize pull requests more by reviewing them faster and actively working to move them forward in status
